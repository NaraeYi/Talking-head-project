# 512x512 크롭 기준 설명

## 전체 프로세스

### 1단계: 얼굴 검출 (InsightFace)
```python
src_face = self.face_analysis_wrapper.get(
    frame_rgb,
    flag_do_landmark_2d_106=True,
    direction="large-small",  # 여러 얼굴 중 큰 얼굴 선택
)
```
- **입력**: 비디오 프레임
- **출력**: 얼굴 정보 (106개 랜드마크 포인트)
- **기준**: 여러 얼굴이 있으면 "large-small" 규칙으로 가장 큰 얼굴 선택

### 2단계: 랜드마크 정제 (Human Landmark Runner)
```python
lmk = self.human_landmark_runner.run(frame_rgb, lmk)
```
- **입력**: 106개 랜드마크 포인트
- **출력**: 정제된 203개 랜드마크 포인트
- **목적**: 더 정확한 얼굴 구조 파악

### 3단계: Bounding Box 계산
```python
ret_bbox = parse_bbox_from_landmark(
    lmk,
    scale=2.2,  # scale_crop_driving_video
    vx_ratio=0.0,
    vy_ratio=-0.1,  # 위로 10% 이동 (이마 영역 포함)
)
```

**계산 과정**:
1. **랜드마크 중심점 계산**: 모든 랜드마크 포인트의 평균
2. **크기 계산**: 랜드마크가 차지하는 영역의 최소/최대 좌표
3. **정사각형 변환**: 가로/세로 중 큰 값으로 통일
4. **Scale 적용**: `크기 × 2.2`
   - 2.2배 확대 → 얼굴 주변 영역(이마, 턱 등) 포함
5. **오프셋 적용**: 
   - `vy_ratio=-0.1`: 위로 10% 이동 (이마 영역 더 포함)
   - `vx_ratio=0.0`: 좌우 이동 없음

**결과**: 얼굴 중심의 정사각형 bbox

### 4단계: 전체 비디오의 평균 BBox 계산
```python
global_bbox = average_bbox_lst(trajectory.bbox_lst)
```
- 모든 프레임의 bbox를 평균내어 **일관된 크롭 영역** 계산
- 비디오 전체에서 얼굴이 움직여도 같은 크롭 영역 사용

### 5단계: 정사각형 크롭 영역 계산
```python
# cvt_LP_bbox 또는 cvt_LP_bbox_nopad
cx = (x1 + x2) / 2  # 중심점
cy = (y1 + y2) / 2
half_w = (x2 - x1) / 2  # 반폭

# 정사각형으로 변환
x1 = cx - half_w
x2 = cx + half_w
y1 = cy - half_w
y2 = cy + half_w
```

### 6단계: 크롭 + 512x512 리사이즈
```python
ffmpeg -vf "crop={rw}:{rh}:{x1}:{y1},scale=512:512"
```

## 핵심 파라미터

### `scale_crop_driving_video = 2.2`
- **의미**: 얼굴 크기의 2.2배 영역을 크롭
- **효과**: 
  - 값이 클수록 → 더 넓은 영역 (이마, 턱 더 포함)
  - 값이 작을수록 → 얼굴에 가까운 영역

### `vy_ratio_crop_driving_video = -0.1`
- **의미**: 위로 10% 이동
- **효과**: 이마 영역을 더 많이 포함

### `vx_ratio_crop_driving_video = 0.0`
- **의미**: 좌우 이동 없음
- **효과**: 얼굴 중심 유지

## 크롭 기준 요약

1. **얼굴 중심**: 랜드마크 포인트의 중심
2. **크기**: 얼굴 크기의 2.2배
3. **형태**: 정사각형 (가로=세로)
4. **위치 조정**: 위로 10% 이동 (이마 포함)
5. **일관성**: 전체 비디오의 평균 bbox 사용
6. **최종 해상도**: 512x512로 리사이즈

---

## 왜 2.2배인가?

- **1.5배**: 얼굴만 (이마/턱 일부 잘림)
- **2.0배**: 얼굴 + 약간의 여유
- **2.2배**: 얼굴 + 이마/턱 충분히 포함 (현재 설정)
- **2.5배 이상**: 너무 넓음 (배경 많이 포함)

2.2는 얼굴 주변 영역을 적절히 포함하면서도 배경을 최소화하는 균형점입니다.
